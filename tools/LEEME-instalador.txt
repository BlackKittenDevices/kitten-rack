KITTEN RACK - instalador para el M-VAVE FM-1
============================================

Qué hay en esta carpeta
  KittenRack.pyw            EL INSTALADOR CON VENTANA: doble clic y listo
  editor/                   el editor del rack, para usar sin internet (lo abre el instalador)
  instalar_kitten_rack.py   el mismo instalador en modo texto (por si la ventana no abre)
  fm1_install.py            el método de instalación de Felucca que usan los dos
  kitten-rack-*.fwsc        el firmware
  SHA256SUMS                las huellas para comprobar que el archivo llegó entero

Antes de instalar
  1. Necesitás Python 3.8 o más nuevo (python.org o la Microsoft Store).
     En Windows no hace falta instalar nada más: usa el MIDI del sistema.
  2. Respaldá los patches y canciones del firmware que tenés ahora (Kitten Synths: con su editor).
     KITTEN RACK usa su propio banco de patches y el anterior puede perderse.
  3. Conectá el FM-1 por USB con un cable de datos y cerrá todo programa que use MIDI
     (editores web, DAW, el editor de Kitten Synths).

La ventana del instalador
  BUSCAR FM-1            muestra qué firmware tiene el FM-1 ahora
  INSTALAR KITTEN RACK   sube el firmware (uno o dos minutos; no desenchufes hasta que diga "Listo").
                         Si algo se corta, apretalo de nuevo: el FM-1 queda esperando y se termina.
  EDITOR OFFLINE         abre el editor de esta carpeta en tu navegador (Chrome o Edge), con MIDI.
                         Funciona mientras la ventana del instalador esté abierta.
  EDITOR ONLINE          abre el editor en internet (https://blackkittendevices.github.io/kitten-rack/)
  OTRO FIRMWARE...       instala otro .fwsc, por ejemplo Kitten Synths para volver atrás
  BAJAR EDITOR OFFLINE   baja la última versión del editor a la carpeta editor/

  El editor y el instalador no pueden usar el MIDI a la vez: para instalar, cerrá la pestaña del editor.

Después, en el FM-1
  En el primer arranque KITTEN RACK escribe sus 33 patches de fábrica. Al actualizar, los patches de
  fábrica que nunca editaste se reemplazan solos por los nuevos (los tuyos no se tocan).
  SEL      el RACK (los módulos del patch)
  EDIT     el patcheo: CABLE NUEVO, CABLES (sacar), AGREGAR MODULO, QUITAR MODULO (SELECT elige,
           SEL dos veces lo saca con sus cables). EDIT de nuevo sale
  FX       salta entre los efectos
  LFO      salta entre las fuentes de sonido y los moduladores
  ENV      salta entre las envolventes y los filtros
  ARP      prende / apaga el arpegiador y muestra su página (modo, ritmo, octavas, largo)
  SEQ      la pantalla del secuenciador (piano roll): SELECT elige la nota, ALGO el paso, SEL tocado
           pone o saca la nota ahí (SEL sostenido: canciones), las teclas blancas también ponen pasos,
           OCT- / OCT+ las páginas (hasta 64 pasos). Sin paso apretado: K1 pasos, K2 ritmo, K3 swing,
           K4 tempo. REC sostenido 4 segundos borra el patrón
  REC      graba desde cualquier pantalla: corriendo, graba donde va; parado, espera la primera nota
           y arranca solo. REC de nuevo deja de grabar (sigue sonando)
  HOME     en la pantalla de los módulos: el osciloscopio, otra vez: los visuales, otra vez: vuelve
  SAVE     elegí un lugar con SELECT: SAVE guarda ahí (si hay otro patch, SAVE de nuevo lo pisa),
           SEL carga el que está ahí, HOME sale. El patch se guarda entero: sonido y secuencias.

El editor, en vivo con el FM-1
  Abrí el editor (offline u online, en Chrome o Edge) y apretá el botón FM-1 de arriba:
  lee el patch que toca el FM-1 y desde ahí lo que movés en uno lo hace el otro (perillas, cables,
  módulos, notas). ROLL en el módulo PATTERN abre el piano roll. AL FM-1 guarda en un lugar del banco.
  Para instalar firmware, primero desconectá el editor (botón FM-1) o cerrá su pestaña.

Sin ventana (modo texto)
  python instalar_kitten_rack.py                       instala
  python instalar_kitten_rack.py --solo-info           solo muestra qué firmware tiene
  python instalar_kitten_rack.py --paquete ARCHIVO.fwsc   instala otro firmware
